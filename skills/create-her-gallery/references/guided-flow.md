# Guided flow

Lead one stage at a time. Start each message with a compact marker such as `第 1/7 步 · 她是谁`. Do not show the whole questionnaire, ask for technical configuration, or continue past an approval gate. Skip questions already answered and allow the user to return to an earlier stage.

## 1. She and you

Ask who the gift is for, how the gallery should address her, the giver's relationship to her, and the occasion. Confirm the nickname or approved display name before continuing.

## 2. Stories and experiences

Ask for memories in small conversational batches. Cover important periods, concrete moments, habits, phrases, places, objects, work, friendships, change, and anything sensitive to omit. Summarize known facts separately from interpretation and ask the user to correct them.

## 3. Words and structure

Offer 2–3 genuinely different narrative frameworks based on the interview. Let the user choose or combine them. Draft the title, preface, chapters, captions, and dedication, then request factual and emotional approval. Do not ask for photos until the written frame is stable.

## 4. Photos and cartoon animation

Ask the user to provide the selected photos. Inventory and group them by chapter. Offer 2–3 consistent cartoon directions, create only 1–2 samples, and request approval before batch processing. Follow [cartoon-animation.md](cartoon-animation.md) to create three-second original-over-animation clips.

## 5. Music and background

Offer the three bundled backgrounds first, then allow a user image or a currently reusable online image. Offer user-provided audio or three licensed healing instrumental candidates. Show previews and record both choices before building.

## 6. Build

Create and validate the manifest, prepare media, embed every asset locally, and build one HTML. Resolve validation errors without asking the user technical questions unless a creative choice is genuinely required.

## 7. Preview and revise

Open the HTML locally. Guide the user through the cover, text, each media sequence, music, background, mobile layout, and ending. Convert feedback into a short revision list, implement it, and preview again. Deliver only after approval.
